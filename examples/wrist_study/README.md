## 候选如何构建

[candidate/model.xml](candidate/model.xml) 是独立左手研究入口，不覆盖原模型。重新执行既有源特征分区代码：源轮廓/孔洞→二维凸区域→精确源三角面裁剪→三维凸包；壳壁按周向/轴向分区，法兰底板与围壁分开，复用19块既有局部特征输入。**没有复制右侧交付OBJ；这是原方法的重执行，不声称发明了新方法。** 原构建代码、输入SHA、日志及306块来源映射均有记录。

实际得到link5 **147**、法兰 **159**，合计306；不是硬凑数量。其中link5侧板108、壳壁36、实体3；法兰侧板121、局部特征19、底板4、环壁15。共19,490顶点、37,756三角面，最小面法向宽度约0.183mm。与右侧既有诊断306的编译顶点、面和geom局部变换306/306精确一致，确认没有重复施加法兰装配变换。

细分主要用于维持孔槽、凹口和壳体壁面的间隙；现有15凸包会把同一部件的不同支撑面连成封口。成功任务中腕部均没有实际负载接触，**不能因此断言这些非接触区域的细分冗余**：其作用包含避免内部假接触。本轮未做逐块消融，没有证据决定哪些块可以删除。

左手手部76块、机械定义、惯性、关节、线性Mimic、驱动、摩擦、solver、接触资格及控制全部保留；没有继承右手B驱动。XML去除授权腕部差异后完全相同，编译物理字段核对通过。候选有452项资源引用，在仅含main和候选的干净目录内可独立加载，18D state / 13D action不变；运行时不依赖历史目录。来源及许可继续遵循仓库的 [来源说明](../../licenses/SOURCES.md)和[法兰溯源](../../licenses/flange-provenance.json)。

## 唯一一次完整左手回归

原生Reset、控制器缓存和全部非腕部编译字段精确核对后，执行5750/5750步、230/230条原动作。无原硬停止；最大Mimic误差0.001001rad、臂跟踪误差0.078150rad、手—碗交叠0.580mm；没有腕部接触。完整状态/动作JSONL与左手历史SHA相同：`880581b82882313c4abc4c9c838402be6ed04eac18dd5c30ee3780258a27fafa`。

从真实接触力另行复核：第3642步出现正力拇食对向接触，第4044步离开环境支撑，随后无环境再支撑。完整hold **750/750步＝1.5秒**均存在正力对向接触、无环境支撑；最终相对250步**post-step沉降位置抬升103.952mm**，相对Reset抬升33.363mm。原轨迹中的高度字段来自RK4末子阶段缓存；这两个post-step数值独立标注，没有混用。原生柜顶任务仍为`false`，`strict_grasp_success_claim=false`。

本轮新显式积分合计 **7414步＝1664步短窗微基准＋唯一5750步原生回归**。两次前置接入阻塞均发生在0步：一次为旧资源路径失效，一次为对旧适配器的可选参数触发冻结源码SHA检查。分别修正资源解析、恢复旧适配器原字节；未放松检查。独立入口只在注册时显式选择候选分片源，仍使用原适配器/控制器；没有积分后的重试或旧runner覆盖。
