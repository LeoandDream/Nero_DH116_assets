# 模型与动力学建模

## 机械结构

NERO 提供 7 个旋转关节，DH116-L000-A1 左手提供 11 个关节，其中 6 个主动通道通过 5 组线性 Mimic 关系带动其余关节。18D 状态顺序及 13D 动作定义见 [robot-contract.json](robot-contract.json)。

质量、惯性、关节轴、限位和线性 Mimic 以归档源 URDF 为依据；可移植描述与原字节快照分别位于 `urdf/` 和 `urdf/source/`。当前连接采用有来源记录的厂家法兰安装假设，不等同实机装配标定。源描述缺失或填零的阻尼、摩擦及驱动参数，不应被解释为硬件实测值。

## 驱动与动力学

| 部分 | 模型表达 |
| --- | --- |
| 机械臂 | 7 个 motor actuator，原生输入为力矩；由下游关节位置控制器计算 |
| 灵巧手 | 6 个 MuJoCo position actuator，输入为主动关节目标角；每路固定 `kp`、`kv` |
| 手指联动 | 5 个 equality joint constraint，使用源 URDF 的线性 Mimic 系数 |
| 数值设置 | MuJoCo 3.2.3，RK4，物理步长 0.002 s |

已执行场景采用原生 robosuite 1.4.1 JointPositionController 的 `set_qpos` 绝对位置入口和 MuJoCo position 伺服。位置伺服增益与约束数值参数属于已有仿真配置，不是新底层控制器，也不是硬件标定增益。MJCF 中 NERO 每路 ±100 的力矩控制范围仅是模型配置，不能作为厂商额定力矩声明；DH116 真实力矩／速度上限仍未知。

Robot action 的前 7 维是绝对关节位置 rad，后 6 维是 [-1, 1] 的独立绝对手位置；它必须经过位置控制与手部角度映射，不能直接当作同维度的 MJCF `ctrl`。

## 碰撞代理

可视网格保留机构外形，接触计算使用分块凸代理，避免整件单凸包对凹部和装配空间的过度填充。

| 组件 | 凸代理数量 |
| --- | ---: |
| NERO 机械臂 | 51 |
| DH116 灵巧手 | 76 |
| 法兰连接件 | 8 |

主要接触的拇指固定指尖 `finger14_link` 和食指固定指尖 `finger23_link` 各采用 12 块；分区来自原三角面，凸包使用原顶点生成，保留源面归属与编译后的覆盖核对。其余手部沿用既有代理。原始 source／visual 不因这次细分而修改。

相对两指尖各 8 块、全手 68 块的版本，固定采样中的误占距离 P95 分别由 1.188→1.011 mm、1.239→1.063 mm；相同命令的白碗动态对照中，最大手—碗代理交叠由约 0.695→0.580 mm。两版均观察到抬升。这些是限定样本和单次运行的结果，不是全表面误差上界或成功率提升保证。[对照依据](VALIDATION.md)

## 自碰撞过滤

MJCF 显式排除固定底座与第一连杆这一对内部接触：

```xml
<contact>
  <exclude body1="robot0_base_link" body2="robot0_link1" />
</contact>
```

该对在来源 SRDF 中标记为 `Adjacent`。过滤仅作用于指定 body 对，没有全局关闭手部与外部物体碰撞。这里的“一对”是显式排除项数量；实际接触还取决于引擎默认过滤、刚性组及 geom 掩码，不能解释为其他任意几何对都一定参与接触。

## 已验证范围与使用边界

来源模型已完成源机械字段核对、有限姿态与几何检查，以及原生 LIBERO 白碗的动态闭合、抬升和持握验证。交付时提取机器人模型并静态核对结构、物理字段和参考姿态；完整任务、控制适配和运行记录在原实验工程维护。[结果与版本对应](VALIDATION.md)

适用范围是已记录控制参数与允许近似下的机器人仿真接入。尚未覆盖完整放置任务、全工作空间可靠性、多 seed 成功率和实机校准。凸代理、原生物体碰撞表示与软接触均会引入差异；仿真接触距离不是源三角面或真实材料的穿透深度。
