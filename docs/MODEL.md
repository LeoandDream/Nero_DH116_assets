# 模型规格与动力学建模

本文描述 [NERO × DH116](../README.md) 交付模型的结构、控制和物理表达。模型入口为 [`mjcf/nero_dh116.xml`](../mjcf/nero_dh116.xml)；静态展示场景为 [`examples/scene.xml`](../examples/scene.xml)。

## 1. 机器人结构

| 项目 | 规格 |
| --- | --- |
| 机械臂 | NERO，7 个旋转关节 |
| 灵巧手 | DH116-L000-A1 左手，11 个关节 |
| 手部驱动 | 6 个独立主动通道 + 5 个线性 Mimic 约束 |
| 状态维度 | 18 个关节位置，具体次序见 [robot-contract.json](robot-contract.json) |
| 驱动器 | 机械臂 7 个 motor、灵巧手 6 个 position actuator |

关节轴、限位、质量和惯性以归档的源 URDF 为机械依据；源文件通过 [`urdf/source/`](../urdf/source/) 保留，便于核查坐标定义与参数来源。带厂家法兰的组合描述是当前装配假设，**不等于已取得实际 NERO–DH116 安装方案的标定结果**。

## 2. 动力学与驱动

模型包含 MuJoCo 所需的刚体惯性、关节与约束、Actuator 和接触几何。MJCF 中的物理步长为 **0.002 s**，积分器为 **RK4**；该时间步长不代表下游策略或真实硬件的控制频率。

| 部分 | MJCF 原生控制含义 |
| --- | --- |
| NERO 7 关节 | motor 力矩输入；模型给出每路 ±100 的仿真控制范围，不应当作厂商额定力矩承诺 |
| DH116 6 主动关节 | position servo，输入为对应主动关节的角度目标（rad） |
| DH116 5 被动联动关节 | Equality joint constraint，按源线性 Mimic 关系耦合 |

外部约定的 **13D robot action** 不等同于 MuJoCo 原生 `data.ctrl`：机械臂 7D 是绝对关节位置目标（rad），灵巧手 6D 是独立归一化位置目标（[-1, 1]）。使用时必须通过相应的关节位置控制器和手部通道映射转换；本资产包**不提供**完整的动作执行适配器。

手部位置伺服的固定增益是仿真配置值，并非实机标定参数。源描述缺少或填零的阻尼、摩擦、速度和力矩信息，不应被解释为真实硬件的测量结果。

## 3. 碰撞与接触建模

可视网格用于呈现机构外形，接触计算则使用**分块凸网格代理（convex collision proxies）**，以便在 MuJoCo 中建立可计算的接触几何。代理并非原始外形的逐点精确表示；接触位置、面积和抓持行为仍会受到几何近似和接触参数影响。

| 组件 | 交付的分块代理数量 |
| --- | ---: |
| DH116 灵巧手 | 76 |
| NERO 机械臂 | 51 |
| 安装连接件 | 8 |

模型保留手部与外部物体的接触定义。`<contact>` 中包含直接相邻 `robot0_base_link` 与 `robot0_link1` 的一组排除；这一排除不表示全局关闭自碰撞，也不表示可以忽略其余物理接触。

碰撞代理用于在几何精度与数值求解之间取得折中。**不能仅凭代理数量或模型外观证明材料摩擦、真实抓持机理以及全工作空间的接触保真度。** 网格资源、来源场景和哈希记录见 [`SOURCE_MANIFEST.json`](../SOURCE_MANIFEST.json)。

## 4. 坐标、装配与场景边界

- URDF 和 MJCF 中保留相应关节的轴、范围、质量和惯性表达；坐标与单位应通过调用方的仿真环境再次核对。
- 当前组合使用有来源说明的连接法兰假设；真实手眼标定、安装偏差与设备通信不在模型交付范围内。
- MJCF 的参考姿态供初始化和静态查看使用，不构成有效抓取初态保证。
- 本仓库不包含实验室厨房场景、操作物体配置、策略、训练数据或硬件接口。

## 5. 适用范围

适合：机器人外形展示、静态结构检查、下游 MuJoCo 环境接入，以及在集成正确控制器后开展独立动力学测试。

尚未由本交付包独立证明：真实硬件力控和摩擦参数准确、所有关节姿态数值稳定、指定操作任务的接触／抓持保真、Sim2Real 性能。

测试入口及当前证据覆盖范围见 [验证状态与适用范围](VALIDATION.md)。
